# Security checklist (аудит v0.6, розділ 11, етап 0)

Звіт кроку 13 і кроку 14: пункт → де це зроблено → чим покрито. Цілі, замовлення, flood оплати і токен monobank належать пізнішим етапам.

| Пункт | Реалізація | Тест |
|---|---|---|
| Зріз: view/update/delete лише власнику. `administer lifebalance snapshots` нікому не видається. | `SnapshotAccessControlHandler`. Дозвіл є в анотації сутності і відсутній у ролях `config/sync`. | `SnapshotKernelTest::testOnlyTheOwnerCanViewOrDelete`, `testPremiumAnswersFollowEntitlement` |
| Опубліковані системні критерії бачать залогінені. Premium-текст лише за entitlement. Адмін-операції через `administer lifebalance criteria`. | `CriterionAccessControlHandler`, `EntitlementChecker`. | `CriterionKernelTest`, `QuestionnaireFormTest`, `EntitlementCacheTest` |
| Premium лише через `EntitlementChecker`. Обхід POST без entitlement відхиляється. | `EntitlementChecker::hasPremium()`. У модулі немає ролі доступу. | `EntitlementKernelTest`, `SnapshotKernelTest::testPremiumAnswersFollowEntitlement`, `DraftKernelTest::testRejection` |
| Немає `views_data` і collection route для зрізів, JSON:API, REST, Commerce. Views UI лише в dev-split. | Зрізи без `views_data`. Views увімкнено для списку рекомендацій. У `config/sync` немає jsonapi, rest, commerce, views_ui, dblog, devel, automated_cron. | `SiteExtensionTest` |
| UUID в URL замість числового id. | Маршрути історії, порівняння і видалення беруть UUID. | `HistoryTest`, `CompareTrendTest`, `HistoryKernelTest::testForeignDeleteBreadcrumbStaysQuiet` |
| `site_manager` керує критеріями, секторами і налаштуваннями, без доступу до зрізів і без операцій Premium. Обліковий запис 1 щодня не використовується. | Роль у `user.role.site_manager`. | `support_manager` бачить метадані, адреси й історію доступу і керує ручним Premium. Зрізів не бачить. Платний запис ця форма не змінює. | Роль у `user.role.support_manager`. Форми за `manage lifebalance premium`. Історія за окремим дозволом. | `AdminPremiumTest` |
| Зміни стану через Form API або POST з CSRF-токеном. | Форми Drupal. `POST /api/draft` вимагає `_csrf_request_header_token`. | `DraftKernelTest::testRouteAndController`, `DraftApiTest` |

| Flood: зріз ≤ 50/добу, draft ≤ 120/хв. | `flood` у `WheelForm` і `DraftController`. | `WheelFormTest`, `DraftKernelTest::testRouteAndController` |
| Персональні сторінки: cache context `user`, `Cache-Control: private, no-store`. | `PrivateCacheSubscriber` і `#cache` на формах і контролерах. | `WheelFormTest`, `QuestionnaireFormTest`, `HistoryTest`, `CompareTrendTest`, `AccountDataTest`, `AccountExportTest`, `DraftApiTest`. Контекст `user` у доступі: `SnapshotKernelTest` |
| Сторінки з Premium-критеріями залежать від користувача і межі доступу. | `EntitlementChecker::getCacheability()`: контекст `user`, тег `lifebalance_entitlement:{uid}`, max-age до найближчої межі. | Експорт: зрізи, оцінки, орієнтири, текст ревізії, нотатки, чернетка, статус Premium. | `PersonalExport`. | `AccountDataKernelTest::testExportContainsOnlyThisAccount`, `AccountExportTest` |
| Видалення: зрізи, відповіді, чернетка, social_auth, entitlement. | `hook_user_predelete` у `UserHooks`, `AccountDeleteForm`. | `AccountDataKernelTest::testPredeleteRemovesPersonalData`, `AccountExportTest::testExportAndDeletion` |
| У логах немає оцінок, відповідей і нотаток. | Повідомлення лише з uid або ключем каталогу: `UserHooks`, `EntitlementManager`, `UserAuthenticator`, `CriterionImporter`. | Ручна перевірка цих чотирьох викликів перед релізом |
| Privacy notice. Метатеги на публічних сторінках `/`, `/privacy`, `/terms`, `/refunds`. | `/privacy` містить розділ про платежі. `/terms` і `/refunds` — заготовки: реквізити й текст оферти має додати власник. Глобальні, 403, 404, node, user і taxonomy теги порожні. | `AccountExportTest`, `ReleaseHardeningTest` |
| Секрети лише в env / `settings.local.php`. | `example.settings.local.php`. У `config/sync` client secret і пароль пошти порожні. `settings.local.php` у `.gitignore`. | `SiteExtensionTest` (пароль `mailer_dsn` є null). Секрети OAuth — ручна перевірка `config/sync/social_auth_*.settings.yml` |
| Довірені хости і cookie. | `settings.php`: шаблон хоста, `HttpOnly`, `SameSite=Lax`, `Secure` (якщо не `DRUPAL_COOKIE_SECURE=0`). | Ручна перевірка на DDEV, 2026-10-11: чужий `Host` → 400; `session.cookie_secure/httponly/samesite` = `1/1/Lax`; шаблон `^lifebalance\.ddev\.site$` |
| Dev-модулі не в production-конфігу. | `config_split` split `dev` (status false): `dblog`, `devel`, `views_ui`. `views` лишається увімкненим для бібліотеки рекомендацій. | `SiteExtensionTest::testDevSplitStaysInactive` |
| CSP, HSTS, frame-ancestors, Referrer-Policy. | `seckit.settings`: `default-src 'self'` і хости Google та Facebook, `script-src 'self'`, `frame-ancestors 'none'`, HSTS на рік без subdomains і preload, `Referrer-Policy: strict-origin-when-cross-origin`, `X-Frame-Options: DENY`. Seckit 2.0.3 не має полів `form-action` і `navigate-to`. `PaymentPageCspSubscriber` додає їх із `'self'`, хостами входу Google і Facebook та `https://pay.mbnk.biz`. Хост оплати не входить у `script-src` і `default-src`. | `ReleaseHardeningTest::testHeadersAndPublicMetatags`, `PaymentCspTest` |
| Лист відновлення пароля. | Core Symfony Mailer, ключ `system.mail:mailer_dsn`. Секрет лише в `MAILER_DSN`. | `ReleaseHardeningTest::testPasswordResetMailIsCollected`. Доставка і спам — ручна перевірка релізу |
